# 校园二手交易平台测试计划
## 1. 项目概述
项目名称：校园二手交易平台
技术栈：SpringBoot + Vue + MySQL
项目功能：面向在校学生的二手物品交易平台，支持用户注册、登录、商品搜索、首页展示。
测试角色：测试人员

## 2. 测试目标
1. 验证用户模块、首页、搜索模块功能是否符合业务需求
2. 发现功能缺陷、前端交互问题、安全漏洞
3. 输出测试用例、缺陷报告、测试总结，评估系统质量
4. 重点验证输入校验、异常处理、SQL注入安全风险

## 3. 测试环境
- 前端：Vue本地启动
- 后端：SpringBoot本地启动
- 数据库：MySQL
- 浏览器：Chrome
- 辅助工具：Chrome F12开发者工具、Navicat、Swagger

## 4. 测试范围
✅ 在测：用户注册、用户登录、首页展示、商品搜索
❌ 本次暂不测试：商品发布、订单、收藏、后台管理

## 5. 测试类型
功能测试、界面交互测试、安全测试、异常测试

## 6. 测试方法
等价类划分法、边界值分析法、错误推测法

## 7. 交付物
- 用户模块测试用例
- 缺陷报告
- 测试总结
