# 注册模块测试用例

| 用例ID | 模块 | 用例标题 | 前置条件 | 输入 | 预期结果 |
| ---- | ---- | ---- | ---- | ---- | ---- |
| ZC1 | 注册 | 合法信息注册成功 | - | 合法用户名、合法学号、合法邮箱、6~18位密码，两次密码一致 | 注册成功 |
| ZC2 | 注册 | 用户名已被占用 | 用户已注册 | 已存在用户名，其余字段合法 | 提示 “用户名已被注册” |
| ZC3 | 注册 | 学号已被占用 | 学号已注册 | 已存在学号，其余字段合法 | 提示 “学号已被注册” |
| ZC4 | 注册 | 邮箱已被占用 | 邮箱已注册 | 已存在邮箱，其余字段合法 | 提示 “邮箱已被注册” |
| ZC5 | 注册 | 邮箱格式错误 | - | 无 @符号 / 缺少后缀，如 abc123 | 提示 “邮箱格式错误” |
| ZC6 | 注册 | 学号格式错误 | - | 学号位数不足 / 含字母符号，如 12345 | 提示 “学号格式错误” |
| ZC7 | 注册 | 密码长度不足6位 | - | 密码：123，确认密码一致 | 提示 “密码长度不能少于6位” |
| ZC8 | 注册 | 两次密码不一致 | - | 密码：abc123，确认密码：abc456 | 提示 “两次输入的密码不一致” |
| ZC9 | 注册 | 邮箱为空提交 | - | 邮箱留空，其余字段合法 | 提示 “邮箱不能为空” |
| ZC10 | 注册 | 学号为空提交 | - | 学号留空，其余字段合法 | 提示 “学号不能为空” |
