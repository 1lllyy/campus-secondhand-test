# 测试总结
## 一、测试概述
本次对校园二手交易平台V1.0版本开展手工功能测试，覆盖注册模块、登录模块、商品搜索模块；使用等价类划分、边界值分析法设计测试用例，在本地前后端启动环境开展测试。

## 二、测试范围
1. 用户注册：用户名、手机号、学号、邮箱、密码、确认密码校验
2. 用户登录：用户名密码校验、提示信息校验
3. 商品搜索：关键词检索、联想下拉、特殊字符、超长文本、空输入场景

## 三、测试产出
1. 测试计划
2. 登录、注册、搜索模块测试用例（Markdown + Excel）
3. 缺陷报告，合计9个缺陷：严重1个、高3个、一般5个

## 四、测试结论
系统基础功能可以跑通，但存在较严重的安全风险（SQL注入）、页面崩溃、登录异常问题；前端表单校验逻辑不稳定，多处校验规则矛盾、错误提示缺失，建议开发优先修复严重、高等级bug，修复完成后进行回归测试。

## 五、建议
1. 修复搜索模块特殊字符过滤，杜绝SQL注入风险
2. 统一手机号、学号、密码的前后端校验规则，消除校验矛盾
3. 完善所有接口返回提示文案，避免空白红色提示
4. 增加前端输入长度限制，防止超长输入导致页面崩溃
