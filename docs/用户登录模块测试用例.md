# 登录模块测试用例

| 用例ID | 模块 | 用例标题 | 前置条件 | 输入 | 预期结果 |
| ---- | ---- | ---- | ---- | ---- | ---- |
| DL1 | 登录 | 合法用户名 + 合法密码登录 | 已注册 | 用户名（4~16位字母数字）、6~18位密码 | 登录成功 |
| DL2 | 登录 | 已存在用户名注册 | - | 已注册用户名 | 提示用户名已被占用 |
| DL3 | 登录 | 用户名包含特殊符号 | - | 用户名：admin@123 | 提示用户名只能是字母、数字、下划线 |
| DL4 | 登录 | 密码小于6位 | - | 密码：123 | 提示密码长度不能少于6位 |
| DL5 | 登录 | 用户名长度不足4位 | - | 用户名：ab | 提示用户名长度 4~16 位 |
