# 搜索模块测试用例

| 用例ID | 模块 | 用例标题 | 前置条件 | 输入 | 预期结果 |
| ---- | ---- | ---- | ---- | ---- | ---- |
| SS1 | 搜索 | 正常关键词搜索，存在商品 | 未登录 / 已登录 | Redmi | 正常展示匹配商品列表 |
| SS2 | 搜索 | 无匹配关键词搜索 | - | 苹果笔记本 99999 | 页面展示【暂无相关商品】提示 |
| SS3 | 搜索 | 特殊符号 % 搜索 | - | %% | 后端转义，当成普通字符搜索，不能返回全部商品 |
| SS4 | 搜索 | 超长文本搜索 | - | 几百字超长文本 | 前端限制输入长度，提示关键词过长，禁止提交 |
| SS5 | 搜索 | 点击搜索联想下拉选项 | - | 输入 Redmi，出现下拉联想词 | 点击联想词自动填入输入框并搜索 |
| SS6 | 搜索 | 空关键词点击搜索 | - | 搜索框为空 | 提示请输入搜索关键词 |
