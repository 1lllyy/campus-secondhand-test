# 缺陷报告
项目名称：校园二手交易平台
测试版本：V1.0
测试环境：前端Vue、后端SpringBoot、MySQL
测试人员：测试

| BugID | 模块 | 缺陷标题 | 严重等级 | 复现步骤 | 实际结果 | 预期结果 |
| ---- | ---- | ---- | ---- | ---- | ---- | ---- |
| BUG001 | 注册模块 | 手机号格式校验逻辑不稳定 | 一般 | 1.进入注册页面<br>2.输入不同开头11位手机号提交 | 有时提示手机号格式不对；部分号码提示已注册，校验规则混乱 | 严格按照手机号规则校验，规则统一稳定 |
| BUG002 | 登录模块 | 注册成功账号无法登录，无明确错误提示 | 高 | 1.注册新用户，注册成功<br>2.使用该用户名+密码登录 | 页面只出现红色空白提示，无文字说明，登录失败 | 登录成功；失败时给出清晰提示（用户名不存在/密码错误） |
| BUG003 | 首页 | 首页图片裂图，资源404 | 一般 | 1.打开首页 | 首页图片无法加载，控制台404 | 首页图片正常渲染展示 |
| BUG004 | 搜索模块 | 搜索下拉选项点击无响应 | 一般 | 1.搜索框输入关键词唤起下拉联想<br>2.点击下拉选项 | 点击无任何反应 | 点击联想词自动填入搜索框并触发搜索 |
| BUG005 | 搜索模块 | 输入%%%搜索，存在SQL注入风险 | 严重 | 1.搜索框输入%%%点击搜索 | 返回商品数据，未做特殊字符转义过滤 | 对特殊字符做转义，当做普通文本检索，禁止返回全部数据 |
| BUG006 | 搜索模块 | 输入“Redmi，苹果笔记本99999”搜索页面空白 | 高 | 1.搜索框输入Redmi，苹果笔记本99999，点击搜索 | 页面空白，无提示 | 正常展示暂无商品或者匹配商品 |
| BUG007 | 搜索模块 | 超长文本搜索，先展示商品后网页崩溃 | 高 | 1.搜索框输入超长文本，点击搜索 | 短暂展示商品，随后网页无法正常运作 | 前端限制输入长度，提前拦截，禁止提交超长内容 |
| BUG008 | 登录模块 | 数据库内MD5密码账号登录时触发前端密码长度校验拦截 | 一般 | 1.数据库user表存在密码明文为123456的账号<br>2.页面登录输入用户名、123456 | 前端弹出提示密码应在6-18个字符 | 校验逻辑统一，123456满足6位下限，允许提交交由后端校验 |
| BUG009 | 注册模块 | 学号10位合法内容出现飘红校验异常 | 一般 | 1.注册页面输入刚好10位合法学号<br>其余字段全部合法 | 学号输入框异常飘红提示格式错误 | 10位学号正常通过校验，不报错 |
