# 校园二手交易平台 - 手工测试项目
> 技术栈：SpringBoot + Vue + MySQL
> 角色：测试人员
> 测试工具：Chrome DevTools、Navicat
> 项目描述：校园二手物品交易平台，在本地搭建前后端独立测试环境，完成手工功能测试。

## 📖 项目简介
面向在校学生的二手物品交易平台，本次主要针对**登录模块、注册模块、商品搜索模块**开展功能测试，使用等价类划分、边界值分析法设计测试用例，共发现9个缺陷，包含1个高危SQL注入漏洞。

## ⚠️ 重点缺陷
1. 搜索框输入 `%%%`，存在SQL注入风险（严重）
2. 超长搜索文本会导致网页崩溃（高）
3. 注册成功账号登录失败，无文字提示（高）
4. 手机号、学号校验逻辑不稳定，存在校验异常
5. 搜索联想下拉点击无响应
6. 首页图片资源404裂图
