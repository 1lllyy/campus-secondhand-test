# 校园二手交易平台 - 手工测试项目
> 技术栈：SpringBoot + Vue + MySQL
> 角色：测试人员
> 测试工具：Chrome DevTools、Navicat、Swagger

## ✅ 项目简介
面向在校学生的二手物品交易平台，包含用户注册登录、商品搜索、首页展示等功能。
独立搭建本地测试环境，采用手工功能测试，使用等价类划分、边界值分析、错误推测、安全测试等方法设计用例。

## 📋 测试范围
用户模块（注册、登录）、首页模块、商品搜索模块

## 🐛 重点缺陷
1. 搜索框输入 `%%%` 存在SQL注入风险（高危P0）
2. 手机号校验逻辑不稳定
3. 登录失败无文字提示，仅红色标识
4. 超长搜索文本导致页面崩溃
5. 搜索指定关键词页面空白
